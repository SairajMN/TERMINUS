# Design System Builder

A structured design engineering skill for turning visual references and product specifications into production-grade design systems. Designed for front-end engineers and autonomous coding agents.

## Usage

Provide a reference screenshot, URL, or aesthetic description, and specify the target framework (e.g. Tailwind CSS v4, CSS Modules, styled-components).

**Example prompts:**
- "Extract a design system and Tailwind config from this modern dashboard screenshot"
- "Create a cohesive, high-contrast dark mode design system for a developer tools CLI"
- "Generate design tokens and UI components matching Stripe/Linear aesthetics"

---

## Standard Design System Tokens

A complete design system generated by this skill must specify:

1. **Color Palette & Contrast Ratios (WCAG 2.1 AA Compliance)**:
   - Neutral baseline (`background`, `surface`, `border`, `subtle`, `text-primary`, `text-secondary`, `text-muted`)
   - Primary brand color with 50-950 scale
   - Semantic accents: `success`, `warning`, `destructive`, `info`
2. **Typography Hierarchy**:
   - Monospace font for code/data (e.g. JetBrains Mono, Fira Code)
   - Display/Sans font for UI (e.g. Inter, Plus Jakarta Sans, Geist)
   - Standard scale: `xs` (12px), `sm` (14px), `base` (16px), `lg` (18px), `xl` (20px), `2xl` (24px), `3xl` (30px)
   - Leading/Line-height pairs and letter-spacing for dense UI vs editorial text
3. **Spacing & Sizing Rhythm**:
   - 4px baseline grid (`p-1` = 4px, `p-2` = 8px, `p-3` = 12px, `p-4` = 16px, `p-6` = 24px)
   - Component heights: Buttons (32px compact, 40px standard, 48px large)
4. **Elevation & Radii**:
   - Border radius scale (`rounded-sm` 4px, `rounded-md` 6px, `rounded-lg` 8px, `rounded-full` 9999px)
   - Subtle layer shadows and 1px border separation for dark mode (`border-neutral-800/80`)
5. **Component Standards**:
   - Interactive button states: `default`, `hover`, `active`, `focus-visible`, `disabled`, `loading`
   - Form inputs, cards, tables, badges, modals, and tooltips
