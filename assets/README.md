# TERMINUS — Terminal Frame Brand Assets

This package contains the TERMINUS Terminal Frame identity in the requested asset formats.

## Requested files

- `terminus-activitybar.svg` — compact 24×24 monochrome IDE activity-bar icon.
- `terminus-favicon.svg` — standalone scalable favicon mark.
- `terminus-icon-isometric.png` — 1024×1024 transparent PNG with subtle monochrome extrusion.
- `terminus-icon.png` — 1024×1024 transparent PNG icon.
- `terminus-logo.svg` — horizontal icon + wordmark lockup, transparent background.
- `terminus-wordmark.svg` — wordmark-only SVG, transparent background.

## Additional dark-background variants

- `terminus-logo-inverted.svg`
- `terminus-wordmark-inverted.svg`

## Notes

- All assets use the same Terminal Frame geometry: four open corner brackets, a geometric T, and a small endpoint block.
- SVG files are vector-based and have transparent backgrounds.
- Wordmark SVG uses a font stack beginning with Inter and Geist. For pixel-identical rendering across environments, convert the text element to paths using your brand's chosen font before final production distribution.
- The activity-bar asset uses a light neutral gray (`#C8C8C8`) suitable for a dark IDE sidebar. Adjust that single color if your host requires a different theme treatment.
