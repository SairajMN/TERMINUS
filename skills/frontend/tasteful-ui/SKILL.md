# Tasteful UI Engineering

Helps coding agents deliver polished, refined, human-crafted interfaces that avoid generic "AI-generated" styling.

## The Anti-Generic UI Checklist

1. **Avoid Purple/Violet AI Default Gradients**:
   - Instead, use deliberate, brand-specific color pairings (e.g. deep ink blue `#0E1726` with warm brass `#B99A5F`, or crisp forest slate `#1B2A44` with pale parchment `#D7DBE0`).
2. **Typography with Weight & Rhythm**:
   - Never use default Times or unstyled Arial.
   - Use distinct weight pairings (e.g. `font-semibold` titles with `font-normal` body at `leading-relaxed`).
   - Monospace for hashes, commands, paths, and token counts.
3. **Subtle Micro-Interactions**:
   - Transitions on hover and focus: `transition-all duration-150 ease-out`.
   - Accessible focus rings: `focus-visible:ring-2 focus-visible:ring-offset-2`.
   - Responsive click feedback: `active:scale-[0.98]`.
4. **Information Hierarchy & Density**:
   - Use whitespace and muted text colors rather than heavy border lines to separate content.
   - Truncate long identifiers gracefully with middle ellipses or tooltips.
5. **Dark Mode Excellence**:
   - True dark mode uses layered tones (`#0B0F17` base, `#111827` cards, `#1F2937` borders) rather than pure `#000000` pitch black against harsh `#FFFFFF`.
